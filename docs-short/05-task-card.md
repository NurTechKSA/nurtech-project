# Карточка задачи (Task, Bug, Subtask)

Связан с [01-scope.md](01-scope.md), [04-board.md](04-board.md), [06-create-task-dialog.md](06-create-task-dialog.md). Макеты: [wireframes/card/](wireframes/card/) — `task.svg` (диалог: Task и Subtask), `page.svg` (отдельная страница), `tabs.svg` (вкладки «Время» и «История»), `popups.svg` (выпадающие окна и диалоги), `states.svg` (состояния).

## 1. Назначение и оболочки
Единое место просмотра и правки задачи: поля, теги, описание, подзадачи, связи, ссылки, комментарии, время, история. **Содержимое — один компонент**, который живёт в двух оболочках:
- **Диалог поверх доски.** Открывается с доски (двойной клик, Enter, клик по ключу): к адресу доски добавляется `?task=PROJ-123`. Модальный: фон затемнён, закрывается ✕, Esc и кликом вне диалога; закрытие убирает только `task` из адреса, фильтры остаются; «Назад» браузера закрывает диалог. В шапке есть ↗ «Открыть на отдельной странице».
- **Отдельная страница** `/project/PROJ/tasks/PROJ-123` под верхней панелью. Так открываются ссылки из чата и закладки; ⧉ копирует именно этот адрес. Вместо ✕ слева от ключа ссылка «← К доске» (последняя использованная доска проекта).
- Подзадача, родитель, связанная задача открываются в той же оболочке: в диалоге меняется `?task=`, на странице — адрес страницы.
- Просмотр: все роли (`task-view`). Права на действия — раздел 7.

## 2. Типы и поля
| Поле | Task | Bug | Subtask |
|---|---|---|---|
| Статус | ✓ | ✓ | ✓ |
| Приоритет (Low / Medium / High / Critical) | ✓ | ✓ | ✓ |
| Тип | Task ↔ Bug | Task ↔ Bug | фиксирован |
| Направление (если у проекта есть) | ✓ | ✓ | ✓ |
| Исполнитель, Ревьюер | ✓ | ✓ | ✓ |
| К дате | ✓ | ✓ | ✓ |
| Оценка (время) | ✓ | ✓ | ✓ |
| Затрачено (сумма списаний, только чтение) | ✓ | ✓ | ✓ |
| Родитель | — | — | только чтение |

Теги — чипы под названием у всех типов. Блоки: описание; подзадачи (у Task и Bug); связи; ссылки; вкладки «Комментарии», «Время», «История». В шапке: ключ, значок типа, ⧉, «создана N назад · Автор · обновлена N назад» (нейтральная форма, по `updatedAt`).

## 3. Раскладка
- **Шапка:** ключ и значок типа, ⧉ «Копировать ссылку»; справа в диалоге ↗ и ✕; на странице слева «← К доске».
- **Левая колонка:** название (крупно), теги, описание, подзадачи, связи, ссылки, вкладки.
- **Правая колонка:** панель полей на затенённом фоне, одна строка на поле: название слева, значение справа. Под «Исполнитель» — «Назначить на меня»; под «Оценкой» и «Затрачено» — «по подзадачам: …» (только если есть подзадачи).
- Диалог — около 900 px шириной, на всю высоту окна с прокруткой содержимого; страница — та же раскладка на ширину контента.

## 4. Поведение
**Название.** Правится кликом; Enter сохраняет, Esc отменяет; пустое не сохраняется; больше 100 символов — «Не больше 100 символов».

**Описание.** Markdown. Просмотр — отрендеренный текст; клик по полю открывает редактор с панелью форматирования и переключателем «Редактор / Просмотр». Пустое описание — подсказка «Добавьте описание». У viewer не кликабельно. «Сохранить» / «Отмена». Закрытие диалога или уход со страницы с несохранёнными изменениями — «Закрыть без сохранения?» («Остаться» / «Закрыть без сохранения»). До 5000 символов. Рендер — [03](03-ui-rules.md), раздел 9.

**Поля панели.** Сохраняются сразу после выбора (оценка и срок — по Enter или потере фокуса). Запросы одного поля идут по очереди; при ошибке значение откатывается к последнему успешному ответу сервера и показывается «Не удалось сохранить поле «…»» с «Повторить».
- **Статус:** список статусов проекта. Смена — `POST /tasks/:id/move` без соседей (задача встаёт в конец колонки). Для статуса с `requiresReason` (Blocked, Cancelled) — диалог «Причина *», как на доске: «Подтвердить» всегда активна, пустая причина — «Укажите причину», «Отмена» оставляет прежний статус, причина сохраняется комментарием.
- **Исполнитель и Ревьюер:** поиск по участникам проекта; первые пункты «Я» и «Не назначен»; «Назначить на меня» — то же, что «Я».
- **К дате:** календарь, «Сбросить» очищает; просроченный срок у незакрытой задачи — красным и с иконкой часов.
- **Оценка:** `2h 30m` (часы и минуты); пусто разрешено; неверный формат — ошибка под полем.
- **Теги:** «+ Тег» — ввод с подсказками из тегов проекта; если такого нет — «Создать «…»» (`tag-create`); ✕ на чипе снимает тег без подтверждения. Набор тегов уходит целиком по той же очереди. Если тег с таким названием уже успели создать (409), показывается сообщение, список тегов перезапрашивается.
- **Затрачено:** только чтение.

**Подзадачи.** Заголовок «Подзадачи N из M» с мини-прогрессом закрытых (категория done). Строка: ключ, название, статус, аватар исполнителя. Клик открывает подзадачу в той же оболочке. «+ Подзадача» — [диалог создания](06-create-task-dialog.md) с типом Subtask и этим родителем. У подзадачи блока нет. «по подзадачам: …» — сумма оценок и сумма затраченного по подзадачам, с подсказками ⓘ «Сумма оценок подзадач» и «Сумма времени, затраченного на подзадачи»; собственные значения родителя в сумму не входят. Данные подзадач приходят в ответе карточки.

**Связи.** «Блокирует», «Заблокирована». «+ Связь» — окно: тип и поиск задачи по ключу или названию (того же проекта, без самой задачи). Связи сгруппированы по типу; у строки ключ, название, статус и 🗑 с подтверждением «Удалить связь с PROJ-144?». Цикл блокировок — сообщение бэкенда (409), связь не создаётся.

**Ссылки.** URL с названием (merge request, документ). «+ Ссылка»: адрес * (`http://` или `https://`) и название. 🗑 с подтверждением «Удалить ссылку?».

**Комментарии.** Счётчик на вкладке — `commentCount`. Плоский список от старых к новым, поле ввода внизу (markdown, «Отправить»). У комментария: аватар, имя, время, пометка «изменён»; у комментария-причины — пометка «Причина смены статуса». Действия: «Ответить» (вставляет `@username` в поле; уведомлений нет); у **своего** — «Изменить» и «Удалить» (любая роль, включая viewer); у **чужого** admin и owner видят «Удалить», остальные — только «Ответить». «Удалить» спрашивает «Удалить комментарий?». Больше 20 — последние 20 и «Показать ещё» (загруженные присоединяются, дубли по `id` отбрасываются). Свой новый комментарий добавляется из ответа `POST`. До 2000 символов.

**Время.** «Затрачено X из Y» и ссылка «Списать время» (фокус в форму). Список: дата, автор, длительность, комментарий; своё можно изменить и удалить (admin и owner — любое), удаление — «Удалить запись о времени?». Форма «Новая запись»: время * (`2h 30m`, от 1 минуты до 24 часов), дата (по умолчанию сегодня, не позже завтра), комментарий; кнопка «Списать». У viewer — только чтение.

**История.** Кто, что, было → стало, когда; сгруппировано по дням; нейтральная форма: «Иван П. · Статус: To do → In progress», «Иван П. · Задача создана». Попадают: статус, исполнитель, ревьюер, приоритет, тип, направление, срок, оценка, теги, связи, ссылки, создание. Комментарии и списания не попадают.

## 5. Состояния
Загрузка (индикатор в диалоге или на странице); задача не найдена или нет доступа (404: «Задача не найдена или нет доступа», на странице — ссылка «К доске»); роль viewer (нет «+ Тег», «+ Подзадача», «+ Связь», «+ Ссылка», формы времени, поля без правки; комментарии доступны); пустое описание; редактирование описания; закрытие с несохранённым описанием; диалог причины; комментарии для admin и owner. Пустые блоки: «Подзадачи», «Связи», «Ссылки» — только кнопка добавления (у viewer блок скрыт); «Комментариев пока нет»; «Списаний пока нет»; «История» не бывает пустой (первая запись — создание). Кадры — `wireframes/card/states.svg`.

## 6. Адреса и обновление
- Диалог: `/project/PROJ/board/:id?task=PROJ-123` (параметр `task` добавляется к текущему адресу доски с фильтрами). Страница: `/project/PROJ/tasks/PROJ-123`.
- Данные карточки перечитываются при возврате на вкладку браузера и после своих действий (ответ ручки возвращает актуальный `TaskDetail`). Параллельная правка того же поля — побеждает последнее сохранение.
- После закрытия диалога доска перезапрашивается.

## 8. API
- Карточка — `GET /projects/:projectId/tasks/by-key/:key` (`projectId` — по ключу проекта из адреса и списку `GET /projects`): поля, подзадачи, связи, ссылки, суммы по подзадачам, `commentCount`.
- Поля — `PATCH /tasks/:id` (ответ — актуальная карточка); статус — `POST /tasks/:id/move`.
- Теги проекта — `GET /projects/:projectId/tags`, новый тег — `POST`; участники — `GET /projects/:projectId/members`; статусы и направления — `GET /projects/:projectId/statuses`, `/subsystems`.
- Связи и ссылки — `POST /tasks/:id/links`, `DELETE /tasks/:id/links/:linkId`, `POST /tasks/:id/urls`, `DELETE /tasks/:id/urls/:urlId`; поиск для связи — `GET /projects/:projectId/tasks/search`.
- Вкладки — `GET|POST /tasks/:id/comments`, `PATCH|DELETE /comments/:id`; `GET|POST /tasks/:id/worklogs`, `PATCH|DELETE /worklogs/:id`; `GET /tasks/:id/history`.
ТЗ — [backend/02](backend/02-tasks.md), [03](backend/03-board-and-move.md), [04](backend/04-comments-worklogs.md).
