# Общие правила интерфейса (MVP)

Правила, общие для всех экранов, чтобы ученики не решали их заново на каждой странице. Сжатая версия `docs/12-ui-rules.md` без правил вырезанных экранов. У правила указано, как его проверить: **axe** (расширение или `@axe-core/playwright`), **Lighthouse** (Accessibility ≥ 90) или **ревью**.

## 1. Язык и термины
- Интерфейс только на русском. Подписи полей: «Исполнитель», «Ревьюер», «Направление», «К дате», «Оценка», «Затрачено». Названия статусов — данные проекта.
- **Пишутся по-английски** (имена собственные): типы Task, Bug, Subtask; приоритеты Low, Medium, High, Critical; роли Owner, Admin, Member, Viewer. Во фразах те же понятия — по-русски: «владелец проекта», «исполнитель».
- Типы связей — «Блокирует», «Заблокирована» (в API `blocks` / `blocked_by`).
- «Задача» — сущность; «карточка задачи» — диалог или страница подробного просмотра; «карточка» на доске — элемент колонки. Кнопки добавления: «+ Задача», «+ Подзадача», «+ Связь», «+ Ссылка», «+ Тег».
- **Общее сообщение приложения** (тост) — всплывающее сообщение об ошибке или результате действия («Не удалось …», с кнопкой «Повторить», где повтор уместен).

| Понятие | По-русски | В API и коде |
|---|---|---|
| Исполнитель | исполнитель | `assignee`, `assigneeId` |
| Ревьюер | ревьюер | `reviewer`, `reviewerId` |
| Автор задачи | автор | `reporter` |
| Направление | направление | `subsystem` |
| Затраченное время | списание времени, «Затрачено» | `worklog`, `spentMinutes` |
| Копирование адреса | «Копировать ссылку» | — |
| Серверная часть | бэкенд | — |

## 2. Формы и диалоги
- **Кнопка отправки всегда активна**: ошибки показываются под полем после нажатия, фокус переходит на первое поле с ошибкой (`aria-invalid="true"`). Проверка: ревью, на пустой форме у кнопки нет `disabled`.
- **Исключение — формы правки существующих данных** (профиль): «Сохранить» неактивна, пока нет изменений.
- Обязательное поле отмечено «*»; подписей «(необязательно)» нет.
- **Несохранённые изменения — две кнопки:** «Остаться» и «Закрыть без сохранения». Вопрос задаётся при закрытии заполненной формы создания и изменённого описания карточки; пустая форма закрывается сразу.
- **Подтверждение удаления.** Удаление комментария, списания, связи, ссылки подтверждается окном «Удалить …?» с кнопками «Отмена» и «Удалить» (опасная, не основной синий цвет). Снятие тега с задачи (✕ на чипе) — не удаление записи, подтверждения нет.
- Кнопки диалога одной ширины; во время отправки поверх диалога индикатор, текст кнопки не меняется. Проверка: ревью.
- Поля карточки сохраняются автоматически; ошибка сохранения откатывает значение и показывает общее сообщение.
- Если у проекта нет направлений, поле «Направление» и фильтр не показываются (шаблон `simple`).

## 3. Состояния экранов
- У каждого экрана с данными есть кадры: **загрузка** (индикатор поверх контента), **пусто** (подсказка, что делать), **«ничего не найдено»** (кнопка «Сбросить») — там, где есть поиск и фильтры.
- Кнопка сброса поиска и фильтров везде — «Сбросить».
- Ошибки сети и сервера — общим сообщением; отдельных экранов ошибок нет, кроме 404 и 403 на странице ресурса (раздел 8). Сообщение исчезает через 8 секунд или по ✕; ошибки валидации общим сообщением не показываются.

## 4. Клики и клавиатура
- Одинарный клик по карточке на доске выделяет её; открывают задачу двойной клик, Enter у выделенной и одинарный клик по ключу (ключ — ссылка).
- Esc закрывает диалог, окно и выпадающий список; в формах с несохранёнными данными сначала вопрос из раздела 2.
- Перетаскивание не имеет клавиатурной альтернативы: её заменяет поле «Статус» в карточке.

## 5. Доступность и читаемость
- У каждой иконки-кнопки есть подсказка (`tuiHint`) и `aria-label` (раздел 7). Проверка: axe, `button-name`.
- Цвет не единственный сигнал: статус — точка и текст; приоритет — цвет и буква; просроченный срок — красный и иконка часов; блокировка — ⛔ и текст.
- Текст не мельче 12 px (мелкие размеры на макетах — условность). Контраст текста ≥ 4,5:1 (axe, `color-contrast`): буква приоритета тёмная (`#1b1f3b`) на цвете приоритета; инициалы аватара — тёмные на светлом фоне; негативный текст — токен Taiga UI, а не цвет заливки; вторичный текст — `#6c7088`. Цвета макета, не прошедшие axe, не копируются.
- Эмодзи на макетах (🔍 🗑 📅 ⧉) обозначают иконки: в реализации — иконки Taiga UI.

## 6. Форматы
- Время: `2h 30m` (часы и минуты). Даты: «3 ноя», в формах «дд.мм.гггг». Относительное время: «5 минут назад», «вчера».
- **Даты без времени** (`dueDate`, `date` списания) — строки `YYYY-MM-DD`, в `Date` не преобразуются (западнее UTC сдвинется день); в формах — `TuiDay`. Моменты (`createdAt`, `updatedAt`) — `Date` в поясе браузера. Просрочку отдаёт бэкенд (`isOverdue`).

## 7. Иконки
**🗑 — удаление записи**, **✕ — закрыть окно, диалог, сообщение или снять чип тега**.

| Иконка | Где | Доступное имя |
|---|---|---|
| ✕ | диалог, окно, сообщение; чип тега | «Закрыть»; «Убрать тег» |
| 🗑 | комментарий, списание, связь, ссылка | «Удалить» |
| ✎ | комментарий, списание | «Изменить» |
| ⠿ | карточка на доске | «Перетащить» |
| 👁 | поле пароля | «Показать пароль» / «Скрыть пароль» (`aria-pressed`) |
| ⧉ | шапка карточки | «Копировать ссылку» |
| ↗ | шапка диалога карточки | «Открыть на отдельной странице» |
| ⎇ | блок «Ссылки» | декоративная, `aria-hidden` |
| ⓘ | «по подзадачам» | «Сумма оценок подзадач»; «Сумма времени, затраченного на подзадачи» |

## 8. Ошибки API и реакция фронта
Любая ошибка 4xx и 5xx приходит телом `{ error: { code, message, fields? } }` ([backend/00](backend/00-conventions.md), раздел 3). Общие ошибки решают **перехватчики каркаса** (`core/interceptors/error-notification.interceptor.ts`, 401 — `unauthorized.interceptor.ts`); фронт ветвится **по HTTP-статусу**, а не по `code`. Запрос, ошибку которого страница обрабатывает сама, помечают `HttpContext` с `SKIP_ERROR_NOTIFICATION`.

| Ответ | Реакция |
|---|---|
| Нет сети, таймаут, 5xx | Общее сообщение «Не удалось выполнить действие. Повторите попытку» (с «Повторить» у загрузки и автосохранения). Изменение откатывается |
| 400 | Ошибка фронта: то же общее сообщение, запрос — в консоль |
| 401 | Сбросить состояние, перейти на `/login` с адресом возврата. На форме входа — `message` под формой |
| 403 | Общее сообщение (`message` бэкенда или «Недостаточно прав»); перезапросить права проекта (`GET /projects/:id/me`) и обновить видимость кнопок (задача E0); изменение откатывается |
| 404 на странице ресурса (проект, доска, задача) | Переход на `/not-found`: «Не найдено или недостаточно прав» и «На главную» |
| 404 при действии | Общее сообщение и перезапрос данных экрана |
| 404 на странице приглашения | Экран «Ссылка недействительна» |
| 409 | Откат изменения, общее сообщение с `message` бэкенда, перезапрос данных экрана (доски или карточки). На форме приглашения (`username_taken`) и при создании тега (`name_taken`) — текст под полем по `fields` |
| 422 | Тексты под полями по `fields` из словаря фронта; если поля нет на форме — `message` |
| 429 | На форме входа — «Слишком много попыток. Попробуйте через N мин.» (N — `Retry-After`, округлённый вверх до минуты) |

- **Словарь `FieldErrorReason → текст`** — один файл: `required` — «Заполните поле» (или текст страницы: «Введите название», «Укажите причину», «Выберите родительскую задачу»), `too_long` — «Не больше N символов», `taken` — «Такой логин уже занят» / «Такой тег уже есть», `invalid` у пароля — «Не менее 8 символов, буква и цифра», у текущего пароля — «Неверный текущий пароль», `in_future` — «Дата не может быть позже завтрашней». Неизвестная причина — «Проверьте значение».
- Несохранённый текст (описание, комментарий) при ошибке остаётся на экране.

## 9. Markdown
- Описание и комментарии рендерит `ngx-markdown` (`<markdown [data]="…">`) со встроенным санитайзером Angular. Запрещены `bypassSecurityTrust*`, `SecurityContext.NONE` и `innerHTML` в обход компонента.
- Ссылки открываются в новой вкладке с `rel="noopener noreferrer"`; `javascript:` не работает.
- Проверка: комментарий `<img src=x onerror=alert(1)>` и `[x](javascript:alert(1))` не выполняют код (то же в описании).
